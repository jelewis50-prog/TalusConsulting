# Talus Consulting

Website for Talus, AI training and consulting for businesses. Live at https://talusconsulting.net.

Plain static HTML/CSS/JS hosted on GitHub Pages (branch `main`, root).

- Pages: `index.html`, `services.html`, `courses.html`, `about.html`, `contact.html`
- Styles: `assets/css/site.css` (brand colors: navy #14213D, brass #B08D57, ivory #F6F3EC; fonts Cormorant Garamond + Inter)
- Scripts: `assets/js/site.js` (hero network animation, "Ask Talus" demo)
- `CNAME` sets the custom domain.
